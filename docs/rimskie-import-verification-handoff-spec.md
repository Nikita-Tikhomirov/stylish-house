# Техническое задание: ручная проверка сайта без потери прогресса

## Цель

Доработать локальный сборщик так, чтобы проверка человека на `rimskie.com` была единственной точкой ручного вмешательства. Автоматическое решение или обход проверки в задачу не входит.

## Требуемый сценарий

1. Playwright обнаруживает проверку по видимому DOM, HTTP-ответу и текущему URL.
2. До изменения состояния сохраняются URL, тип операции, категория, товар, очередь, лимит запросов и время последнего обращения.
3. Запуск получает состояние `paused` и причину `challenge`.
4. GUI показывает понятный баннер: какая страница ждёт проверки и что нужно сделать оператору.
5. Окно Chrome с тем же постоянным профилем остаётся доступным оператору.
6. После ручного завершения проверки оператор нажимает `Продолжить`.
7. Сборщик проверяет, что на текущем URL появилась ожидаемая страница категории или товара, и продолжает с сохранённого этапа.
8. Если проверка не завершена, повторного клика и серии запросов нет; GUI остаётся в состоянии ожидания.
9. Перезапуск ПК не теряет checkpoint. Повторное `Продолжить` открывает тот же профиль и ту же сохранённую границу запроса.

## Ограничения

- Не решать CAPTCHA и не имитировать действия человека автоматически.
- Не читать и не экспортировать cookies, local storage, пароли или данные других профилей браузера.
- Не создавать второй параллельный сборщик для одного `run-id`.
- Не сбрасывать счётчик 20 операций в час при перезапуске.
- Не писать данные и профиль на диск `C:`.
- Не изменять production-базу; перед будущими изменениями базы обязателен проверенный бэкап.

## Точки кода

- `scripts/rimskie-import/lib/playwright-transport.mjs` — обнаружение проверки и проверка ожидаемой страницы после ручного действия.
- `scripts/rimskie-import/lib/collector.mjs` — checkpoint и переход `running → paused(challenge) → running`.
- `scripts/rimskie-import/cli.mjs` — удержание владельца запуска и корректное продолжение существующего процесса.
- `scripts/rimskie-import/gui/status-service.mjs` — причина паузы и текущий URL.
- `scripts/rimskie-import/gui/public/app.js` — баннер и кнопка продолжения.

## Обязательные тесты

- Проверка не вызывает автоматический клик.
- При обнаружении проверки URL и очередь записаны до паузы.
- Повторное нажатие `Продолжить` без ручного завершения не создаёт новый donor-запрос.
- После ручного завершения работа продолжается ровно с сохранённого этапа.
- Перезапуск процесса сохраняет лимит запросов и checkpoint.
- Повреждённый checkpoint, чужой URL, другой origin или подменённый профиль приводят к безопасной диагностической остановке.
- GUI после перезапуска показывает ту же причину паузы и тот же текущий товар.
