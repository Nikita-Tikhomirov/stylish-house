# Product popup close control

## Goal

Add one compact blue close control inside the top-right corner of the white product popup without reintroducing the duplicated markup and conflicting styles that broke the previous version.

## Visual design

- The visible cross uses the site blue `#0989ff`.
- The button has a transparent background and no visible border or shadow.
- Exactly two pseudo-elements draw the cross; the button contains no `span`, text glyph, SVG, or icon font.
- The desktop hit area is `36px` square, positioned `10px` from the popup's top and right edges. Each stroke is `18px × 2px`.
- On viewports up to `575px`, the hit area is `40px` square and is positioned `8px` from the popup edges. The visible cross remains `18px`, so it is easy to tap without looking oversized.
- Hover changes only the stroke color to a darker blue. Keyboard focus gets a clear blue outline; no permanent circle or background is added.

## Markup and CSS contract

- `#popupProd` contains one empty `<button type="button" class="prodPopup__close" data-modal-close aria-label="Закрыть">`.
- `#popupProd` is the positioning context for the button.
- The modal wrapper's legacy outer `.modal__close` is hidden only when the wrapper contains `#popupProd`. Other modal types retain their existing close control.
- Popup-close styles live in `resources/css/front-components.css`; no inline styles are added.

## Interaction contract

- Clicking the blue button closes the popup.
- Clicking the dark overlay outside the white popup closes the popup.
- Clicking inside the white popup does not close it.
- The three rules above must hold both for an initially rendered product card and for a card regenerated by AJAX filtering.
- Closing always returns `#popupProd` to `body`, removes the modal wrapper, and restores page scrolling.

The shared delegated modal handler is the single interaction owner. It treats a click as a close request only when the target is a close control or the modal overlay itself. Existing page-specific wrappers may still create the modal structure, but they do not need a second visual or interaction implementation.

## Verification

- Test the shared handler for close-button, overlay, and inside-content clicks.
- Test the popup markup/CSS contract so duplicate children, glyphs, and the old conflicting rules cannot return.
- Build production assets.
- In a rendered browser, verify desktop and `390 × 844` mobile layouts.
- In both layouts, exercise the close button, overlay click, and inside-popup click before and after an AJAX filter refresh.
- Check console errors, scroll restoration, and that exactly one visible product-popup close control exists.
